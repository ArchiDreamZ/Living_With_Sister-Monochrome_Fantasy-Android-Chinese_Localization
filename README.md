## 幽夜彩绘是什么？
“幽夜的优化版彩色包”，简称“幽夜彩绘”，是PC电脑版妹相随用的彩色包，是由彼梦测试群群友“幽夜”在[Daseson的彩色模组](https://github.com/ArchiDreamZ/Living_With_Sister-Monochrome_Fantasy-Android-Chinese_Localization/wiki/%E5%BD%A9%E7%BB%98%E7%9B%B8%E5%85%B3#daseson%E7%9A%84%E5%BD%A9%E8%89%B2%E6%A8%A1%E7%BB%84)与[“一只马儿”彩色包](https://github.com/ArchiDreamZ/Living_With_Sister-Monochrome_Fantasy-Android-Chinese_Localization/wiki/%E5%BD%A9%E7%BB%98%E7%9B%B8%E5%85%B3#%E4%B8%80%E5%8F%AA%E9%A9%AC%E5%84%BFonepony%E7%9A%84%E5%BD%A9%E8%89%B2%E5%8C%85)的基础上，进行调色与重绘的新版彩色包。

他结合了Daseson与一只马儿两种彩绘，剧情背景CG用Daseson的，H部分则在一只马儿基础上对其不完整的H图背景进行重新勾线绘制，对大量高饱和度的Daseson的剧情背景图进行批量降低饱和度，对部分在黑白原版中过于简单潦草的日常背景图(卧室、浴室等)还进行了完全重绘。具体图片对照请看下文。

幽夜彩绘使用广泛，很多人做的整合都使用了幽夜彩绘，以及安卓的巴图勇士与宁宁澄优化版也是（其中巴图勇士DLC版是将幽夜彩绘做了黑白去色处理后使用的）。

幽夜在2024年8月15日发了彩色包1.0，发布于彼梦的安卓精翻测试群与Don的汉化群中。后续在8月16日还针对安卓版做了夜袭优化补丁。

## 我为什么创建这个仓库？
为了作为一个正式发布地，进行介绍与下载，让人们认识幽夜，以及对幽夜彩绘的问题进行修复、继续维护。

幽夜仅将彩色包发在QQ群中，没有在网络上正式公开发布，但即使如此该彩色包依然广为流传，并且网络上包含幽夜彩绘的资源全都没标注作者名，这就很不好了。这导致很多人都在用却不知出处，也不知道作者是谁，也不知道后续更新在哪下载。

并且幽夜发在QQ群里的最初版本的彩色包存在着不少问题，例如贴图没有汉化、不兼容其他模组等，这会让玩家使用时不方便。

因此我做了决定，我要为幽夜彩绘做一个公开的正式介绍，以及一个正式的下载地址。让所有玩家知道他们用的新彩绘是个什么，以及后续彩绘更新在哪下载。

于是我联系了幽夜问了关于他彩绘的大量细节用于介绍，在Github创建一个Branch对幽夜的彩色包进行了正式整理打包，并继续进行修复与维护。

## 彼梦的维护与修复
幽夜彩绘的最初版本也存在不少问题，比如包里为了避免因打包操作失误而遗漏彩绘，所以就将妹相随的所有贴图都加进去了，有的图片有bug，所有带文字的图片都没有汉化，这些问题我都通过这个仓库进行了严谨修复。我在本仓库（在本Branch内）进行了对幽夜彩绘的整理，将幽夜的优化进行分类上传，从而为了后续最严谨的整理与修复。

然后我进行了后续的维护与修复，修复了bug并将所有图中的文字汉化，并且同步移植Daseson彩色模组的更新。

彼梦修复与维护内容：
- 幽夜初版内包含整个妹相随所有贴图，为了避免与其他模组/补丁不兼容，我将其筛选精简，仅留下了彩绘部分。
- 幽夜初版内所有带文字的图片都没汉化，我将其替换为了彼梦精翻项目中的汉化贴图。
- 修复了一个彩色贴图bug。
- 幽夜批量降低了Daseson彩色模组贴图的色彩饱和度，我创建了彼梦分支，将幽夜彩绘分为了“降低饱和度”和“不降低饱和度”的两种版本，供玩家选择。
- 幽夜彩绘是在Daseson彩色模组上优化的，但是Daseson彩色模组还在不断更新，我会将其更新移植到幽夜彩绘里，保持幽夜彩绘的最新实用性。

经过我的整理、修复与汉化，目前在该仓库中的版本就是“幽夜的优化版彩色包”最好的正式发布版。如果想要体验幽夜彩绘，请直接在该仓库内下载。

**彼梦分支**：
关于上文提到的色彩饱和度，有的玩家会觉得Daseson的背景图的色彩饱和度正好，可能不希望使用幽夜降低了饱和度的版本，并且可能有些玩家更希望使用Daseson的H图而不是一只马儿的。

因此我将选择权交给玩家，我为幽夜彩绘创建了一个分支：[幽夜彩绘-彼梦分支版(YouYe_Color_ImagePack-Archi_Fork)](https://github.com/ArchiDreamZ/Living_With_Sister-Monochrome_Fantasy-Android-Chinese_Localization/tree/YouYe_Color_ImagePack-Archi_Fork)

在这个分支中，没有批量降低Daseson背景图的饱和度，并且为了颜色统一，能用Daseson就用Daseson的彩绘，而不用一只马儿。

幽夜彩绘就放在仓库代码区，点击绿色按钮“<>Code”，然后点击“Download ZIP”，即可下载。

或者直接点这里快速访问：

如果你想下载“幽夜彩绘”，请点击：[幽夜彩绘](https://github.com/ArchiDreamZ/Living_With_Sister-Monochrome_Fantasy-Android-Chinese_Localization/archive/refs/heads/YouYe_Color_ImagePack.zip)

如果你想下载“幽夜彩绘-彼梦分支”，请点击：[幽夜彩绘-彼梦分支](https://github.com/ArchiDreamZ/Living_With_Sister-Monochrome_Fantasy-Android-Chinese_Localization/archive/refs/heads/YouYe_Color_ImagePack-Archi_Fork.zip)

如果下载缓慢，可尝试加速地址：[加速地址-幽夜彩绘](https://gh-proxy.org/https://github.com/ArchiDreamZ/Living_With_Sister-Monochrome_Fantasy-Android-Chinese_Localization/archive/refs/heads/YouYe_Color_ImagePack.zip) | [加速地址-彼梦分支](https://gh-proxy.org/https://github.com/ArchiDreamZ/Living_With_Sister-Monochrome_Fantasy-Android-Chinese_Localization/archive/refs/heads/YouYe_Color_ImagePack-Archi_Fork.zip)

### 使用方法：
与其他妹相随彩色包使用方法相同，使用[Wolf RPG 解包工具](https://github.com/ArchiDreamZ/Living_With_Sister-Monochrome_Fantasy-Android-Chinese_Localization/wiki/%E6%B1%89%E5%8C%96%E7%9B%B8%E5%85%B3%E6%8A%80%E6%9C%AF%E5%B7%A5%E5%85%B7#wolf-rpg-%E7%9B%B8%E5%85%B3)，将游戏目录中的.wolf文件解包并删除，然后将彩色包覆盖进去。

解包后，切记一定要删除原.wolf文件，因为游戏引擎会优先读取原.wolf文件，只有被删除后，才会选择读取解包后的文件，这样才会读取解包状态的彩色贴图。
